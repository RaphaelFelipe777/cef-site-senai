# CEF — Confort Eletric Future

Site acadêmico desenvolvido para o projeto do SENAI.

## Estrutura
- `index.html` — estrutura do site
- `style.css` — identidade visual e responsividade
- `script.js` — menu mobile e ano automático
- `assets/` — imagens fornecidas no trabalho

## Publicação
O site é estático e pode ser publicado gratuitamente em GitHub Pages, Netlify ou Vercel.
